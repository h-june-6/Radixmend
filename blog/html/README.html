RadixMend 블로그 글 목차

WBS 16주 계획의 주차에 맞춰 나눈 글들이다. 3주차부터는 서버에서 실험한 내용이다. "선행"이 붙은 글은 그 주차 계획 중 GPU 없이 할 수 있는 부분만 먼저 했다는 뜻이다. 각 글에는 작업하면서 막혔던 문제와 푼 방법(트러블슈팅), 남은 일이 들어 있다.

주차 WBS 단계 글 이번에 한 것 GPU가 필요해 남은 것
0 킥오프 week00_kickoff.md 기술서 기반 프로젝트 소개: 문제, 기존 방법의 한계, 설계, 평가 계획
1 준비 및 기준선 구축 week01.md SGLang v0.5.22 고정, 코드 분석, Triton 백엔드 선정, 실험 환경·워크로드 명세, 결함 주입기 착수 서버에서 모델 실행, 재현 스크립트 완성
2 준비 및 기준선 구축 week02.md SECDED 참조 구현, 단일·이중·삼중 오류 전수 검증, 결함 주입기 완성(CPU) 무결함 기준선 측정, 주입기 서버 연동
3 영향 분석 및 리스크 확인 week03.md 서버 설치 트러블슈팅(CUDA 툴킷, JIT, 쿼터), 버전 하향 후 복귀, 결정적 모드, V 비트별 영향 800회, 커널 오버헤드 선측정, 시행 축소
4 영향 분석 week04.md sink 대 나머지 위치, 인덱스 비트 반전(RQ1-5), 파생 오염 재현(RQ1-6), 성능 기준선
5 영향 분석 정리 및 설계 확정 week05.md 해시 기법 이식과 되쓰기 버그, TOCTOU, RQ1 정리와 설계 변경, HW ECC 실측 제외
6 구현 (모듈 A) week06.md 체크워드 버퍼, decode 커널 융합, extend 사전 검사, 첫 비용 측정
7 구현 (모듈 A) week07.md gate·popc·샘플링·sig 변형, 생성 중 주입, 되쓰기, RQ2 교정·탐지율
8 decode 검사 비용 줄이기 week08.md 재계산 launch 분리(레지스터 255→96), 버린 시도, launch 설정 조정, 모듈 A 파생 오염 실험
9 구현 (모듈 C) week09.md 오류 로그 기반 retract·재계산, poison과 재삽입 되쓰기, FrozenInstanceError, 동시 요청 피해 범위, 강제 재계산 대조로 재계산 경로 차이 확인
10 구현 (모듈 D) week10.md 재사용 prefix 사본, 커널 안 복원, CUDA graph 안전한 무효화, 재계산 0·지연 0.05초, 나중에 찾은 864토큰 TTFT 원인
11 구현 (모듈 B) week11.md node.value 상위 비트·req_to_token 그림자 표, kv_indices 길목 검사, RQ1-5 크래시·변화 0, TTFT +138%와 커널 launch 폭증
12 구현 (모듈 B) week12.md 커널 합치기로 TTFT +0.5%, free_pages 인코딩, seq_lens CPU 사본 복원, 없는 함수 감싸기 실패, 늦은 복원 수정
13 통합 week13.md 네 모듈 통합 결함 시험, 모듈 C overlap 지원, .item() 동기로 TTFT +94% → 비동기 스냅샷 +10%, 2단계 강제 재계산 대조
15 (선행) 평가 완료 week15.md 코드워드 길이 트레이드오프, 3비트 한계 시뮬레이션 실제 플립 분포 반영, 오버헤드, 출력 영향

14, 16주차 글은 아직 없다. 11주차는 처음에 선행 글(인코딩만)로 썼다가 실제 구현 글로 바꿨다(이전 판은 git 기록에 있다).
